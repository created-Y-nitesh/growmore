GROWMORE ANDROID APK DIRECTORY
================================

Place your production-ready Android APK in this directory with the exact name:
growmore.apk

Full Path:
public/downloads/growmore.apk

When a visitor clicks "Download Android App" on the website, the site verifies availability.
If growmore.apk is present here, it will be directly downloaded by the browser.
If absent, the site displays the friendly "Android App Coming Soon" announcement modal.
